How to use this folder

Every document is a single self-contained HTML file — no build step, no dependencies beyond Google Fonts, and all the cross-links are relative. That means:

  • Open index.html in a browser and everything works, straight off disk.
  • Push the folder to GitHub and enable Pages on it — the links resolve unchanged.
  • Each document has a sticky contents rail that highlights the section you are reading, and respects your system light/dark preference.
Two corrections carried throughout

The source markdown says the backend runs on port 3000 and that the AI service uses Groq. Both changed: the backend moved to 3010 because Docker Desktop holds 3000, and the LLM provider is now the Claude API. Where the handbooks and the markdown disagree, the handbooks are current.

Where this comes from. These 44 documents are the taught, navigable edition of 278 markdown files across nine knowledge bases — software-engineering-foundations/ (15 files), onboarding-knowledge-base/ (39), skill-upgrading-knowledge-base/ (54), the three senior standards folders, the interviews/ and interview-prep/ banks, data-science-exercises/, and prep/ (97 technical files) — plus the standalone playbooks and the data science and AI engineering sets. The originals hold the longer code examples and the full lab briefs; these carry the concepts, the mechanisms and the judgement.

Two honest limits. The question banks hold roughly 1,030 source questions and the deep dives about 15,200 lines; documents 28–32 cover every topic area with representative graded examples rather than reproducing every item, and each names its source files in its own footer. And prep/phase-0-orientation/01-resume-claim-audit-and-defensibility-map.md is deliberately excluded — it is a personal CV audit, not technical material.

On what will age. Framework defaults, provider products and tool names will move. The reasoning will not: how systems fail, where authorisation belongs, what a trade-off costs, and how to tell a real improvement from a plausible one.
